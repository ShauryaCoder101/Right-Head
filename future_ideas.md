# 💡 Future Ideas — RecruitIQ

> Features and enhancements for future consideration. Not in current scope.

## Notification Channels
- [ ] **Slack integration** — Send screening completion notifications to Slack channels
- [ ] **Microsoft Teams integration** — Webhook-based notifications for Teams
- [ ] **Custom webhook notifications** — Allow tenants to configure arbitrary webhook URLs for events

## AI Enhancements
- [ ] **Fine-tuned parsing model** — Train on customer resume corpus for higher accuracy
- [ ] **Interview question generator** — Auto-generate role-specific interview questions based on candidate gaps
- [ ] **Candidate outreach drafts** — Auto-draft personalized outreach emails for top candidates
- [ ] **Salary prediction** — Estimate market salary range based on candidate profile and location
- [ ] **Culture fit scoring** — Analyze writing style and values alignment (opt-in only)

## Integrations
- [ ] **Calendar integration** — Schedule interviews directly from shortlist (Google Calendar, Outlook)
- [ ] **Video interview platforms** — Push candidates to HireVue, Spark Hire
- [ ] **Background check providers** — Trigger Checkr/Sterling checks from candidate card
- [ ] **HRIS sync** — Bi-directional sync with BambooHR, Workday HCM

## Analytics & Reporting
- [ ] **Recruiter performance dashboard** — Time-to-fill, pass-through rates, quality of hire metrics
- [ ] **Pipeline funnel visualization** — Sankey diagram from application to hire
- [ ] **Skill trend analytics** — Track in-demand skills across JDs over time
- [ ] **Source quality tracking** — Which upload sources produce highest-scoring candidates

## UX Improvements
- [ ] **Mobile responsive views** — Tablet/phone-optimized shortlist review
- [ ] **Browser extension** — Quick-parse LinkedIn profiles from browser
- [ ] **Keyboard shortcuts** — Power-user keyboard navigation throughout app
- [ ] **Candidate comparison matrix** — Side-by-side comparison of 3+ candidates
- [ ] **Saved search filters** — Save and share filter presets across team

- [ ] **SSO / SAML** — Enterprise single sign-on (planned for Phase 5)
- [ ] **Multi-language support** — i18n for non-English resumes and UI

- [ ] **Usage-based billing** — Meter and bill per resume processed for SaaS pricing
